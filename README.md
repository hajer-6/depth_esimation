# MonoDepth: Monocular Depth Perception for Robot Vision

A computer vision module that uses a single camera to estimate depth and detect black markers relative to a target point. Designed for robotics applications , where precise distance measurement and marker detection are essential.

##  Key Features

- Monocular depth estimation from a single camera
- Black marker detection near target points
- Distance calculation using geometric principles
- Real-time frame processing
- Configurable camera parameters (FOV, sensor dimensions)
